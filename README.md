# troly

Trợ lý cá nhân của Gia Bảo: app Android (Capacitor, giao diện React, plugin Kotlin) cùng máy chủ FastAPI và PostgreSQL, bộ não là Claude API.

- Chat, hồ sơ lõi, chi tiêu, hộp tin, lịch và nhắc, lịch trình kèm Google Maps.
- Nghe thông báo trên điện thoại: Zalo, Telegram, Messenger, SMS, Vietcombank, Techcombank, MoMo.

Tài liệu: [docs/README.md](docs/README.md).

Trạng thái: đã chốt thiết kế, chưa có mã.
